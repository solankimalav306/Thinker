          How answers work

          What Thinker can do

          • Answer questions about the open PDF, with the pages it used.
          • Highlight passages, write structured notes and draw mind maps.
          • Define words in context and build a glossary you can export.

          Reading the answers

          • Document only means the answer comes strictly from your PDF.
          • AI knowledge marks parts that go beyond the document.
          • If Thinker is unsure, it says so. Ask for the source and it will show the page.
