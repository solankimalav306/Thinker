        About the AI Assistant

        What I can do:

        • Answer questions about the open PDF using document content.
        • Highlight text, create structured notes, and generate mind maps.
        • Define terms (context-aware) and build a glossary you can export.

        How to understand my answers:

        • Responses labeled Document Only come strictly from the PDF.
        • Responses labeled AI Knowledge may use background knowledge beyond the PDF.
        • If I'm uncertain, I'll say so. Use the chat buttons to ask for sources or evidence.

        Tip: Use the capability chips on the chat welcome card to try common actions.
